# DC01 DocCraft — 01.5 Business Owner Brief

วันที่: 2026-09-04  
Gate: Business/Market Gate  
สถานะ: PASS

## สรุปสั้น

DocCraft ผ่าน Business/Market Gate หลัง Owner Decisions D1-D2 เพราะตอนนี้ commercial path และ telemetry mode ถูกล็อกแล้ว ตลาดที่มีโอกาสจ่ายเงินจริงยังเป็นตลาดแคบและมีคู่แข่งฟรีเยอะ แต่ paid wedge ชัดพอสำหรับ gate นี้: ไม่ใช่ "จ่ายเพื่อทำเอกสารทั่วไป" เพราะของฟรีแข่งง่ายเกินไป แต่คือ "เอกสารธุรกิจ/ภาษีไทยที่ถูกต้องขึ้น ทำเร็ว พิมพ์ A4 พร้อมใช้ โดยไม่ต้องสมัครระบบบัญชีเต็มรูปแบบ"

D1 ล็อกว่าให้คง product shape แบบ no-login / local-first ไม่ย้าย DocCraft เป็น account/cloud/subscription product และไม่เพิ่ม Phase 7 scope เพื่อ monetization ใน V1

ลำดับ commercial ที่ล็อกแล้วคือ: ปิดงาน Product Phase 4.1 / 5 / 6 ตาม roadmap เดิมก่อน จากนั้นเปิด Public Pilot ฟรี ใช้ pilot วัด tax-document usage, repeat usage, print/export completion, willingness/reason to pay แล้วเมื่อ sellable feature set พร้อมค่อยทดสอบ one-time unlock ราคาประมาณ 299-599 บาท สำหรับฟีเจอร์กลุ่มภาษี/เอกสารสะอาด เช่น ใบกำกับภาษี, WHT, output ไม่มี watermark หรือ clean output คุณภาพพิมพ์ A4

Subscription ไม่ใช่ V1 model ให้กลับมาคิดใหม่หลัง Phase 7+ เท่านั้น เมื่อมี account, cloud, history, reporting จริง

D2 อนุมัติ telemetry สำหรับ Public Pilot แบบ anonymous + consented ขั้นต่ำ โดยห้ามเก็บเนื้อหาเอกสาร ชื่อลูกค้า/บริษัท เลขภาษี จำนวนเงิน หรือ sensitive document fields และคนที่ไม่ยอมให้ telemetry ต้องยังใช้ core functionality ได้เหมือนเดิม

## จุดที่ยัง dissent

1. ควรเก็บเงินจาก V1 ไหม:
   - Candidate A: ฟรีบางส่วน แล้วจ่ายครั้งเดียวเพื่อ unlock ฟีเจอร์ภาษี/clean output
   - Candidate B: อย่าขาย V1 ใช้เป็น free acquisition/validation funnel เท่านั้น
   - Candidate C: one-time purchase น่าทดสอบได้หลัง remediation แต่ checkout ยังไม่อยู่ใน V1

2. subscription หรือ one-time อะไรมีหลักฐานดีกว่า:
   - subscription มีหลักฐานจาก FlowAccount/PEAK/Kitslancer แต่พวกนั้นเป็นระบบ workflow/accounting ที่ใหญ่กว่า V1
   - one-time มีหลักฐานใกล้กว่า DocCraft จาก BillKub ที่ Candidate C ระบุว่า Pro ราคา 299 บาท lifetime

สรุปของ synthesizer: สำหรับ V1 shape ให้ให้น้ำหนัก one-time มากกว่า subscription และใช้ Public Pilot เป็นเครื่องมือ validate ไม่ใช่ข้ออ้างให้ launch paid ทันที

## Recommendation

ให้เดินต่อ และสถานะ Business/Market Gate = PASS

ทางที่ดีที่สุดตอนนี้:

1. แก้ Product Gate Phases 4.1/5/6 ให้เสร็จก่อน อย่าเรียก V1 ว่าขายได้
2. เปิด Public Pilot แบบฟรีเพื่อวัดการใช้จริง
3. เก็บ minimal anonymous + consented telemetry เฉพาะ event ที่ต้องใช้: app opened, document created, tax feature used, preview completed, print/export completed, return/repeat session
4. ใช้ telemetry คู่กับ manual feedback ไม่ใช่แทน feedback
5. ทดสอบ paid intent สำหรับ one-time unlock ราคาประมาณ 299/499/599 บาท เมื่อ feature set ขายได้จริง
6. อย่า commit subscription จนกว่าจะมี Phase 7+ เช่น account, history, cloud, catalog, reporting และเห็น repeat-use จริง

## ทำไมแนะนำแบบนี้

V1 ยังไม่มีเหตุผลพอให้เก็บรายเดือน เพราะผู้ใช้ไม่ได้มี account, history, cloud, catalog หรือ reporting ที่ทำให้กลับมาจ่ายทุกเดือน การจ่ายครั้งเดียวเหมาะกับงานแบบ transactional มากกว่า: "กูต้องออกเอกสารนี้ให้ถูกและดูดีตอนนี้"

แต่ one-time ก็ยังเป็น paid hypothesis ที่ต้อง test เพราะคู่แข่งฟรีเยอะมาก และ BillKub ถ้าข้อมูล Candidate C ถูกต้อง ก็ตั้ง anchor ราคาไว้ที่ 299 บาท lifetime แล้ว Business/Market Gate ผ่านได้ เพราะ Owner ได้ล็อกวิธี validate แล้ว ไม่ใช่เพราะ revenue ถูกพิสูจน์แล้ว

## ทางเลือกที่ไม่แนะนำ

| ทางเลือก | เหตุผลที่ไม่แนะนำ |
|---|---|
| ขาย V1 เป็น subscription ทันที | V1 ไม่มี retention loop และชนกับ FlowAccount/PEAK ที่เป็น full accounting ในราคาไม่สูงมาก |
| usage-based pricing | no-login/local-first วัด usage ยาก และเพิ่ม friction ในตลาดที่มีของฟรี |
| launch paid ทันที | Product Gate ยังไม่ผ่าน และไม่มี pilot evidence |
| ขยายเป็น accounting/e-Tax ใน V1 | หลุด locked V1 boundary |
| ฟรีตลอดแบบไม่มี paid hypothesis | อาจได้ user แต่ไม่ตอบโจทย์ business model |

## Blockers

### Business/Market blockers

| Blocker | สถานะ |
|---|---|
| commercial scope ยังไม่ตัดสินใจ | resolved by D1 |
| telemetry mode ยังไม่ตัดสินใจ | resolved by D2 |
| repeat-use / willingness-to-pay / segment / SKU ยังไม่มีข้อมูลจริง | reclassified เป็น Public Pilot validation objective ไม่ใช่ Business/Market blocker แล้ว |

### Public Pilot validation objectives

| สิ่งที่ต้อง validate | วิธีวัด |
|---|---|
| repeat usage | return/repeat session และ repeated document creation |
| willingness/reason to pay | paid intent test สำหรับ one-time unlock 299/499/599 บาท + manual feedback |
| paid segment | แยก VAT-registered, WHT user, freelancer, shop, service business |
| paid SKU | วัด tax invoice, WHT, clean/no-watermark output, A4 print/export quality ว่าอะไรทำให้คนยอมจ่าย |

### Carry-forward ไม่ควร fail Business Gate ด้วยตัวมันเอง

| local storage data-loss trust risk | Product / Risk / Launch |

## Owner Decisions

1. D1: รักษา no-login/local-first, ทำ Public Pilot ฟรีก่อน, test one-time unlock 299-599 บาทหลัง sellable feature set พร้อม, subscription ไม่ใช่ V1 model
2. D2: Public Pilot เก็บ telemetry ได้แบบ anonymous + consented ขั้นต่ำ ห้ามเก็บ sensitive document data และการปฏิเสธ telemetry ต้องไม่ลด core functionality

## Verdict

Verdict: PASS

DocCraft ผ่าน Business/Market Gate เพราะตลาดและ pain มีจริง มีหลักฐานจากคู่แข่งว่าคนจ่ายให้ workflow เอกสาร/ภาษีไทยได้ และ Owner ได้ล็อก commercial path + telemetry approach แล้ว ช่องว่างเรื่องการใช้ซ้ำ willingness-to-pay segment และ SKU ถูกย้ายเป็น Public Pilot validation objective ตาม D1-D2

PASS นี้ไม่ใช่ approval ให้ launch, ไม่ใช่ approval ให้ build checkout/telemetry ทันที, ไม่ใช่ approval ให้แก้ pricing document และไม่ใช่ approval ให้ทำ subscription V1
