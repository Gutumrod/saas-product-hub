สรุปสั้น

DocCraft ผ่าน Business/Market Gate หลัง Owner Decisions D1-D2 เพราะตอนนี้ commercial path และ telemetry mode ถูกล็อกแล้ว ตลาดที่มีโอกาสจ่ายเงินจริงยังเป็นตลาดแคบและมีคู่แข่งฟรีเยอะ แต่ paid wedge ชัดพอสำหรับ gate นี้: ไม่ใช่ "จ่ายเพื่อทำเอกสารทั่วไป" เพราะของฟรีแข่งง่ายเกินไป แต่คือ "เอกสารธุรกิจ/ภาษีไทยที่ถูกต้องขึ้น ทำเร็ว พิมพ์ A4 พร้อมใช้ โดยไม่ต้องสมัครระบบบัญชีเต็มรูปแบบ"

D1 ล็อกว่าให้คง product shape แบบ no-login / local-first ไม่ย้าย DocCraft เป็น account/cloud/subscription product และไม่เพิ่ม Phase 7 scope เพื่อ monetization ใน V1

ลำดับ commercial ที่ล็อกแล้วคือ: ปิดงาน Product Phase 4.1 / 5 / 6 ตาม roadmap เดิมก่อน จากนั้นเปิด Public Pilot ฟรี ใช้ pilot วัด tax-document usage, repeat usage, print/export completion, willingness/reason to pay แล้วเมื่อ sellable feature set พร้อมค่อยทดสอบ one-time unlock ราคาประมาณ 299-599 บาท สำหรับฟีเจอร์กลุ่มภาษี/เอกสารสะอาด เช่น ใบกำกับภาษี, WHT, output ไม่มี watermark หรือ clean output คุณภาพพิมพ์ A4

Subscription ไม่ใช่ V1 model ให้กลับมาคิดใหม่หลัง Phase 7+ เท่านั้น เมื่อมี account, cloud, history, reporting จริง

D2 อนุมัติ telemetry สำหรับ Public Pilot แบบ anonymous + consented ขั้นต่ำ โดยห้ามเก็บเนื้อหาเอกสาร ชื่อลูกค้า/บริษัท เลขภาษี จำนวนเงิน หรือ sensitive document fields และคนที่ไม่ยอมให้ telemetry ต้องยังใช้ core functionality ได้เหมือนเดิม

Recommendation

ให้เดินต่อ และสถานะ Business/Market Gate = PASS

ทางที่ดีที่สุดตอนนี้:

  1. แก้ Product Gate Phases 4.1/5/6 ให้เสร็จก่อน อย่าเรียก V1 ว่าขายได้
  2. เปิด Public Pilot แบบฟรีเพื่อวัดการใช้จริง
  3. เก็บ minimal anonymous + consented telemetry เฉพาะ event ที่ต้องใช้: app opened, document created, tax feature used, preview completed, print/export completed, return/repeat session
  4. ใช้ telemetry คู่กับ manual feedback ไม่ใช่แทน feedback
  5. ทดสอบ paid intent สำหรับ one-time unlock ราคาประมาณ 299/499/599 บาท เมื่อ feature set ขายได้จริง
  6. อย่า commit subscription จนกว่าจะมี Phase 7+ เช่น account, history, cloud, catalog, reporting และเห็น repeat-use จริง

ทำไมแนะนำแบบนี้

V1 ยังไม่มีเหตุผลพอให้เก็บรายเดือน เพราะผู้ใช้ไม่ได้มี account, history, cloud, catalog หรือ reporting ที่ทำให้กลับมาจ่ายทุกเดือน การจ่ายครั้งเดียวเหมาะกับงานแบบ transactional มากกว่า: "กูต้องออกเอกสารนี้ให้ถูกและดูดีตอนนี้"

แต่ one-time ก็ยังเป็น paid hypothesis ที่ต้อง test เพราะคู่แข่งฟรีเยอะมาก และ BillKub ถ้าข้อมูล Candidate C ถูกต้อง ก็ตั้ง anchor ราคาไว้ที่ 299 บาท lifetime แล้ว Business/Market Gate ผ่านได้ เพราะ Owner ได้ล็อกวิธี validate แล้ว ไม่ใช่เพราะ revenue ถูกพิสูจน์แล้ว
