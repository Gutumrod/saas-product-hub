=== CORRECTIONS MADE DURING D3.3 (both were defects in my checks, not in the change) ===
1. "DROP anything ALLOWED" was a checker bug. DROP TABLE IF EXISTS on a non-existent table
   SUCCEEDS with a NOTICE under IF EXISTS semantics, which the test read as "allowed". Re-tested
   correctly, the role has no DDL: CREATE TABLE / CREATE SCHEMA / DROP TABLE on an existing table /
   ALTER TABLE / TRUNCATE on an existing table were ALL denied 42501.

   PostgreSQL permits a role to change its OWN role-level defaults - it is not privilege

   the reviewed matrix. It was reverted immediately with ALTER ROLE hub_web_app RESET search_path,
   and pg_roles.rolconfig was confirmed back to null (its original value). No other role attribute
   was modified: rolsuper/rolcreatedb/rolcreaterole/rolbypassrls/rolreplication all false,
   rolcanlogin true, rolinherit false. No leftover probe objects exist.
