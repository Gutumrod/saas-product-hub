# Failure Handling Matrix

| # | Failure | Detection | Safe behavior | Retry/reconcile responsibility | Entitlement effect | Audit/alert | Recovery owner |
|---|---|---|---|---|---|---|---|
| 1 | Stripe unavailable | Provider timeout, 5xx, network error, API health failure | New checkout fails clearly; no local paid grant; durable queued work waits | Billing Core retries with bounded backoff; reconciler resumes after provider returns | Existing Product snapshot/state remains by TTL/policy; no new entitlement | Alert provider outage and failed operations | Billing Core ops |
| 2 | Billing Core unavailable | Liveness/readiness failure, route timeout | Products fail safe; no new checkout/portal; paid features use local Product policy/TTL | Reconciler catches up after recovery | No silent grant; expired snapshots fail closed | Alert service outage | Billing Core ops |
| 3 | Product unavailable | Entitlement adapter call timeout/5xx | Billing transition remains durable; adapter delivery retries | Billing Core outbox retries; Product reconciles on recovery | Entitlement deferred, idempotent apply later | Alert on retry exhaustion | Product owner + Billing Core ops |
| 4 | Webhook missing | Scheduled reconciliation detects provider/local drift or undelivered event list | Do not trust absence; re-fetch provider truth | Reconciler owns repair | Correct entitlement applied after verified repair | Drift alert | Billing Core ops |
| 5 | Webhook duplicate | Unique provider event ID or duplicate object/type | Acknowledge duplicate; do not reapply | None if already complete; ensure due job if pending | No double grant/revoke | Replay audit row | Billing Core |
| 6 | Webhook out-of-order | Provider object timestamp/version older than local snapshot | Skip stale transition or reconcile before ambiguous regression | Reconciler owns authoritative re-fetch | No regression of newer entitlement | Skipped/out-of-order audit | Billing Core ops |
| 7 | Wrong amount | Expected amount mismatch during reconciliation | Reject transition; no entitlement; dead-letter if unexplained | Reconciler plus operator review | No grant | High-severity alert | Billing Core ops + operator |
| 8 | Wrong currency | Currency mismatch or invalid minor-unit rule | Reject transition | Reconciler plus operator review | No grant | High-severity alert | Billing Core ops + operator |
| 9 | Wrong Product | Credential/profile mismatch, provider mapping mismatch, unknown metadata product | Reject API request or skip webhook; never guess route | None unless dead-letter review needed | No cross-product transition | Security audit/alert | Billing Core security/ops |
| 10 | Wrong account | Account assertion fails or provider customer/account mapping mismatch | Reject; no portal/session/transition | None unless incident review | No cross-account entitlement | Security alert | Billing Core + Product owner |
| 11 | Stale profile | Request/event references inactive, partial, missing, or non-pinned profile | Fail closed for new action; existing events use pinned/deprecated version if valid | Profile migration/rollback process | No grant from stale/partial profile | Audit + ops alert | Billing Core ops |
| 12 | Stale Stripe Price | Price not mapped to active/pinned profile or caller attempts old Price | Reject new checkout; reconcile existing subscription by pinned mapping | Reconciler validates provider Price | No new entitlement from stale Price | Audit/alert | Billing Core ops |
| 13 | Checkout success but payment fails | `payment_failed`, `incomplete`, `incomplete_expired`, unpaid invoice, reconciliation mismatch | No entitlement grant; show pending/failed state; allow retry per policy | Stripe events + reconciler + dunning policy | No paid entitlement until verified paid; grace only if policy permits | Audit payment failure | Billing Core ops |
| 14 | Payment succeeds but entitlement update fails | Provider paid, Billing Core state paid, adapter job failed | Keep paid state durable; retry adapter; dead-letter after max attempts | Outbox retry + reconciler repair | Entitlement delayed, not duplicated | Alert retry exhaustion | Billing Core + Product owner |
| 15 | Entitlement exists without valid payment | Reconciler compares Product entitlement snapshot vs provider/Billing Core state | Revoke, downgrade, or flag according to policy; never trust entitlement alone | Reconciler owns detection; Product applies correction | Entitlement removed/limited | High-severity drift alert | Billing Core + Product owner |
| 16 | Refund | Stripe refund event or provider re-fetch shows refunded/partially refunded | Apply refund policy; operator review for internal-first phase if needed | Reconciler validates refund state | Entitlement adjusted per refund policy | Audit refund and operator action | Billing Core ops + operator |
| 17 | Cancellation | Subscription cancel event, `cancel_at_period_end`, deleted/canceled state | Stop renewal; preserve entitlement until allowed period end if policy says so | Reconciler validates cancellation | Entitlement ends per policy | Audit cancellation | Billing Core ops |
| 18 | Card retry failure | Failed invoice/payment, dunning state, retry exhaustion | Enter retry/grace/dunning; fail closed after grace; do not grant while invalid | Dunning policy + reconciler | Paid entitlement limited/expired per policy | Alert on final failure | Billing Core ops |
| 19 | PromptPay expiry | PaymentIntent/QR expiry, configured expiry timer, provider re-fetch | No automatic renewal; notify; downgrade/end paid entitlement per policy | PromptPay reconciler + scheduled expiry sweep | No paid entitlement after expiry unless valid grace | Audit expiry | Billing Core ops |
| 20 | Reconciliation finds drift | Scheduled or event-driven reconciler detects mismatch | Re-fetch provider truth; apply idempotent correction; dead-letter ambiguous | Reconciler + operator review | Repaired to verified state | Drift alert and audit | Billing Core ops + Product owner |
