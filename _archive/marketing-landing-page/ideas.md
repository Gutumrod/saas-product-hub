# แนวคิดการออกแบบ Landing Page (Apple-inspired Style) — ServiceBooking

## ทิศทางที่เลือก: Apple Clean & Precision (Apple-inspired)

### Design Movement
Minimalist consumer-tech precision, inspired by Apple product pages: ultra-clean hierarchy, generous whitespace, dark/light contrast cards, subtle background blur, crisp typography, and high-impact hero framing.

### Core Principles
1. **Focus on Clarity:** ทุกส่วนนำเสนอจุดเด่นด้วยตัวหนังสือขนาดใหญ่ ความคมชัดสูง และไม่มีเส้นสายรกตา
2. **Generous Whitespace:** ใช้ช่องว่างรอบองค์ประกอบเพื่อสร้างความรู้สึกพรีเมียมและผ่อนคลาย
3. **Refined Typography:** ใช้ **Noto Sans Thai** เป็นหลัก ผสานน้ำหนัก Light, Regular, Medium, Bold เพื่อสร้างลำดับสายตาที่แม่นยำ
4. **Controlled Accent:** สีหลักเป็นโมโนโครมสะอาด (ขาว, เทาอ่อน, ดำถ่าน) ตัดด้วยสีเขียวเข้มและปุ่มแอคชันที่เด่นชัด

### Color Philosophy
- พื้นหลังสลับระหว่างขาวบริสุทธิ์ (`#FFFFFF`) และเทาอ่อนพรีเมียม (`#F5F5F7`)
- ตัวอักษรสีดำถ่าน (`#1D1D1F`) เพื่อความสบายตาในการอ่าน
- เน้นการใช้งาน subtle border (`#E5E5EA`) และการ์ดโค้งมนนุ่มนวล (`border-radius: 1.25rem`)

### Typography System
- ใช้ **Noto Sans Thai** (น้ำหนัก 300, 400, 500, 700) ทั้งเว็บไซต์เพื่อความต่อเนื่องและสะอาดตา
- หัวข้อใหญ่ใช้ Tracking แคบเล็กน้อย (`tracking-tight`) เพื่อความทรงพลังแบบหน้าผลิตภัณฑ์

### Visual Assets & Layout
- จัดวางแบบ hero-centric ด้วยภาพผลิตภัณฑ์หรือแท็บเล็ตขนาดใหญ่กลางจอ
- การ์ดแพ็กเกจ (Free Trial, Basic, Pro) ออกแบบเป็น floating cards ที่มีความเงาสะท้อนนุ่มนวล (subtle shadow)
- FAQ และ Feature Grid ใช้สไตล์โมดูลาร์สะอาดตา
