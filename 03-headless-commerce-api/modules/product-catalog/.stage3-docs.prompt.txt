## CsvProductRepositoryOptions
{ dataDirectory: string (REQUIRED); lockTimeoutMs?: number (default 3000) }
Behavior:
- Creates dataDirectory recursively; creates 5 CSV files on first use: products.csv, variants.csv, brands.csv, categories.csv, product_images.csv (each with a header row).
- Atomic writes: writes to `<file>.tmp.<uuid>`, fsync, then renameSync over target; a `.bak` copy of the previous file is kept before overwrite.
- Per-file lock via `<file>.lock` created with 'wx' flag; waits (50ms poll) up to lockTimeoutMs, else throws CSV_LOCKED.
- UTF-8, RFC4180-style quoting with "" escaping (supports Thai / commas / newlines).
- Header validation + schema validation + column-count validation + numeric/boolean field corruption detection → CSV_CORRUPTED.
- Multi-tenant isolation: every query/mutation scoped by tenantId+catalogId; cross-tenant lookup returns null / PRODUCT_NOT_FOUND.
- Duplicate SKU enforcement per catalog → DUPLICATE_SKU.
- deleteProduct cascades to variants and product_images rows (same scope).
- searchProducts = listProducts with filters (search matches name/sku/description/brand name/category name, case-insensitive); default sort newest-first (createdAt desc).
- KNOWN LIMITATION (document prominently per BRIEF Section 11): NOT for high concurrency. Writes are serialized by a single-process file lock and the whole table is read into memory on each read; each mutate holds an exclusive lock. For high-write / multi-process / horizontally-scaled workloads use a real database adapter (future Supabase/Postgres). Fine for small-to-medium catalogs, dev, single-process apps.

## LocalMediaStorageOptions
{ baseUploadDir: string (REQUIRED); publicBaseUrl: string (REQUIRED); maxFileSizeByte?: number (default 5 * 1024 * 1024) }
Behavior:
- Creates baseUploadDir recursively.
- upload: rejects file > maxFileSizeByte (INVALID_PRODUCT_DATA); magic-byte MIME detection (JPEG 0xFFD8FF, PNG 8-byte sig, WEBP RIFF....WEBP) and rejects if detected MIME != declared mimeType (MEDIA_UPLOAD_FAILED). Only image/jpeg, image/png, image/webp supported. Generates a UUID filename + extension from detected MIME; original filename sanitized and stored only as metadata originalFileName. Storage key layout: uploads/products/{productId}/{uuid}.{ext}. Writes then fsync.
- delete: idempotent unlink.
- exists, getPublicUrl (publicBaseUrl + / + key), getMetadata (stat + magic-byte mime), move, copy.
- Path traversal protection: resolveStorageKey normalizes backslashes, strips leading slashes, rejects NUL bytes, and assertSafePath ensures the resolved path stays within baseUploadDir else throws STORAGE_ERROR 'Path traversal detected'.
- Service-level uploadProductImage also validates declared mimeType against an allowlist (image/jpeg|png|webp) → INVALID_PRODUCT_DATA.

## Error model (ProductCatalogError, all 12 codes)
| Code | Trigger |
| PRODUCT_NOT_FOUND | get by id/sku/slug of a missing product, or missing image referenced in setPrimaryProductImage/deleteProductImage |
| DUPLICATE_SKU | creating/updating a product or variant whose SKU already exists in the same catalog |
| INVALID_PRODUCT_DATA | invalid create/update input (missing/empty name or sku, negative/non-finite price, bad currency, bad status, bad stockQuantity, invalid custom attribute, bad metadata, missing brand, image size limit, unsupported image MIME, reorder list mismatch) |
| INVALID_VARIANT | variant not found / missing name / non-negative price / invalid attribute |
| INVALID_CATEGORY | category not found, invalid category input, category cycle/self-parent, missing parent category |
| STORAGE_ERROR | low-level storage/provider failure (fs errors, path traversal, CSV lock acquire failure) |
| MEDIA_UPLOAD_FAILED | media upload failed (incl. magic-byte mismatch / corrupted / unsupported file) |
| MEDIA_DELETE_FAILED | media delete failed |
| CSV_LOCKED | file lock not acquired within lockTimeoutMs |
| CSV_CORRUPTED | CSV header missing / schema mismatch / column count mismatch / malformed quote / unclosed quote / corrupted numeric or boolean field |
| PROVIDER_UNAVAILABLE | generic provider/domain operation failure fallback (any non-ProductCatalogError thrown inside a service op) |
| CONFIGURATION_ERROR | missing dataRepository/mediaStorage, or adapter missing required options |

## Security notes to document
1. No secret logging: logger is host-injected; LogEntry never carries credentials; DESIGN mandates logger implementations must never log credentials/keys/secrets.
2. No env access: module never reads process.env/env/globalThis secrets; all config injected.
3. Path traversal protection: LocalMediaStorage resolves keys safely, rejects NUL bytes, keeps paths under baseUploadDir (assertSafePath); filenames sanitized (sanitizeFileName strips control chars, slashes, .. runs, leading/trailing dashes).
4. MIME validation: magic-byte detection server-side; never trusts client-declared MIME alone; allowlist jpeg/png/webp; size limit.
5. Tenant scoping: every op scoped by tenantId+catalogId via CatalogContext; cross-tenant access impossible (null/PRODUCT_NOT_FOUND).
