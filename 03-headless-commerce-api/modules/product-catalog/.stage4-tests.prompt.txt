## Core API contract (verified from source)

### CatalogContext
{ tenantId: string; catalogId: string; actor?: { id: string; type: 'user'|'system'|'api'|'import' } }

### ProductCatalogService methods (all take ctx first)
- createProduct(ctx, input) -> Product
- getProductById(ctx, id) -> Product (throws PRODUCT_NOT_FOUND if missing)
- getProductBySku(ctx, sku) -> Product (normalizes sku via validateSku; throws PRODUCT_NOT_FOUND if missing)
- getProductBySlug(ctx, slug) -> Product (slugifies input; throws PRODUCT_NOT_FOUND if missing)
- updateProduct(ctx, id, input) -> Product
- archiveProduct(ctx, id) -> Product (sets status='archived', archivedAt=now)
- restoreProduct(ctx, id) -> Product (clears archivedAt; status = isActive ? 'active' : 'inactive')
- deleteProduct(ctx, id) -> void (hard delete, cascades variants + images in CSV adapter)
- listProducts(ctx, query?) -> PaginatedResult<Product>
- searchProducts(ctx, query) -> PaginatedResult<Product>
- createVariant(ctx, input) -> Variant ; getVariantById; updateVariant; deleteVariant; listVariantsByProductId(ctx, productId) -> Variant[]
- createBrand / getBrandById / updateBrand / deleteBrand / listBrands(ctx, query?) -> PaginatedResult<Brand>
- createCategory / getCategoryById / updateCategory / deleteCategory / listCategories(ctx, query?) -> Category[]  (NO pagination — returns array)
- uploadProductImage(ctx, input) -> ProductImage
- deleteProductImage(ctx, imageId) -> void
- setPrimaryProductImage(ctx, productId, imageId) -> ProductImage
- reorderProductImages(ctx, productId, imageIdsInOrder[]) -> ProductImage[]
- listProductImages(ctx, productId) -> ProductImage[]

### CreateProductInput
{ sku: string; name: string; slug?; description?; shortDescription?; status?: ProductStatus; brandId?; categoryId?; price: number; compareAtPrice?; costPrice?; currency?; stockQuantity?; trackInventory?; isActive?; isFeatured?; attributes?: CustomAttributeMap; metadata? }
Defaults: status='draft', currency='THB' (config.defaults.currency ?? 'THB'), stockQuantity=0, trackInventory=true, isActive=true, isFeatured=false.

### AttributeValue discriminated union
| { type:'string', value:string }
| { type:'number', value:number }
| { type:'boolean', value:boolean }
| { type:'date', value:string }  // ISO8601
| { type:'enum', value:string, options:string[] }   // value must be in options
| { type:'multi_enum', value:string[], options:string[] } // every value must be in options

### SKU validation
validateSku trims, uppercases, replaces invalid chars with '-', collapses dashes, trims leading/trailing dashes. Result must match /^[A-Z0-9_-]{3,64}$/. Invalid -> INVALID_PRODUCT_DATA. SKU 'HELMET-ADV-001' normalizes to itself. ' helmet adv 001 ' -> 'HELMET-ADV-001'.

### Slug
slugify NFKC-normalizes, lowercases, replaces non-letter/number runs with '-', trims dashes; empty -> 'item'. Thai preserved: 'หมวกกันน็อค ADV' -> 'หมวกกันน็อค-adv'. generateUniqueSlug appends -1, -2 on collision.

### PaginatedResult<Product>
{ items, page, limit, total, totalPages, hasNext, hasPrev }

### Error codes (12): PRODUCT_NOT_FOUND, DUPLICATE_SKU, INVALID_PRODUCT_DATA, INVALID_VARIANT, INVALID_CATEGORY, STORAGE_ERROR, MEDIA_UPLOAD_FAILED, MEDIA_DELETE_FAILED, CSV_LOCKED, CSV_CORRUPTED, PROVIDER_UNAVAILABLE, CONFIGURATION_ERROR.

### Config
createProductCatalogService({ dataRepository, mediaStorage, logger?, auditSink?, defaults?: { currency?, pageSize?, maxPageSize? } }). Missing dataRepository or mediaStorage throws CONFIGURATION_ERROR. default pageSize=20, maxPageSize=100. Query limit above maxPageSize is clamped down; page below 1 clamped to 1.

### CSV adapter
createCsvProductRepository({ dataDirectory: string; lockTimeoutMs?: number }). Creates 5 CSV files on construction. Atomic write (tmp -> fsync -> rename -> .bak). File lock via <file>.lock ('wx' flag, poll 50ms up to lockTimeoutMs=3000, else CSV_LOCKED). UTF-8, RFC4180 quoting. CSV_CORRUPTED on header mismatch, column count mismatch, malformed quote, unclosed quote, corrupted numeric/boolean/JSON field. Tenant isolation by tenantId+catalogId (sameScope). listProducts/searchProducts filter by tenant+catalog.

### Local media adapter
createLocalMediaStorage({ baseUploadDir: string; publicBaseUrl: string; maxFileSizeByte?: number }). default maxFileSizeByte = 5*1024*1024.
upload(input): UploadMediaInput = { tenantId, catalogId, productId, fileName, mimeType, content: Uint8Array|ArrayBuffer, metadata? }. Rejects > maxFileSizeByte -> INVALID_PRODUCT_DATA. Magic-byte detection: JPEG 0xFFD8FF, PNG 8-byte sig, WEBP RIFF....WEBP. detectedMime !== declared mimeType -> MEDIA_UPLOAD_FAILED. Any MIME not in allowlist (image/jpeg, image/png, image/webp) -> MEDIA_UPLOAD_FAILED (from detectMimeType throw). Returns MediaStorageOutput { storageProvider:'local', storageKey, publicUrl, fileSize, mimeType, metadata:{originalFileName} }. Storage key layout: uploads/products/{productId}/{uuid}.{ext}.
delete(storageKey) idempotent. exists(storageKey). getPublicUrl(storageKey) = publicBaseUrl + '/' + key. getMetadata, move, copy.
Path traversal: storageKey with NUL byte or resolving outside baseUploadDir -> STORAGE_ERROR 'Path traversal detected'. sanitizeFileName strips control chars, path separators, '..', leading/trailing dashes.
